# Lumen Ridge Lakehouse

A story-driven write-up (site + ebook) of rehearsing an Azure Databricks lakehouse for **Lumen Ridge**, a fictional betting
operator, on synthetic data and a USD 200 monthly budget. Published with GitHub Pages.

- `index.html`: the storyline and headline numbers
- `ebook.html`: twelve chapters with figures (architecture and gates, summaries, cost, dev/prod promotion barrier)

Lumen Ridge is fictional and all data is synthetic. Written by Claude, reviewed by Codex. Corrections welcome as issues.
