# Lumen Ridge LinkedIn publishing pack

This pack contains ready-to-publish material for a fictional, synthetic-data lakehouse rehearsal. It is written for LinkedIn, including headings, suggested hashtags, visual pairings and accessibility alt text.

## Start here

Open `linkedin-content-pack.md` for:

- one long-form LinkedIn article;
- three short LinkedIn posts;
- a five-slide carousel outline;
- suggested headlines, captions, hashtags and alt text;
- publishing guardrails that keep the fictional rehearsal clear.

## Recommended hashtags

Choose three to five relevant tags per post rather than adding every tag:

`#DataEngineering` `#DataQuality` `#Databricks` `#dbt` `#PowerBI` `#AnalyticsEngineering` `#DataGovernance` `#DevOps`

## Publication note

Describe Lumen Ridge as fictional and the rehearsal data as synthetic. Do not publish internal source names, platform IDs, credentials, tenant details or links to private repositories.
